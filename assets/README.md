# Rainbrand artwork

The approved final Rainbrand icon is pending. It is the only outstanding visual
asset for this package. The icon currently served by the public website is not
the approved Rainbrand artwork, so this draft includes no image and no logo
metadata.

When the approved icon is available, add it at assets/rainbrand-logo.png and set
both `logo` and `composerIcon` in the OpenAI interface metadata to
./assets/rainbrand-logo.png. Rebuild both distribution archives and run ordinary
validation and submission readiness checks.

A primary icon is required for OpenAI submission. Do not substitute generated,
recolored, or historical artwork for the approved asset. The walkthrough
recording is a separate submission requirement described in the root README.
